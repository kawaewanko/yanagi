# Community Bot コマンド一覧

Community Botは、サーバー管理・通知・ロール管理・監視を担当します。

## 基本・情報

| コマンド                    | 内容                                      |
| --------------------------- | ----------------------------------------- |
| `/help`                     | 利用可能なコマンド一覧                    |
| `/ping`                     | 応答速度の確認                            |
| `/userinfo user:<ユーザー>` | ユーザー情報を表示                        |
| `/server-info`              | サーバー情報を表示                        |
| `/bot-status`               | 各Botの稼働状況を表示                     |
| `/metrics minutes:<分>`     | APIの成功・失敗回数を集計表示（管理権限） |
| `/music-history`            | 音楽再生履歴を表示                        |

## 通知・自動化

### RSS通知

| コマンド                         | 内容                           |
| -------------------------------- | ------------------------------ |
| `/rss-add url:<URL> name:<名前>` | RSS/Atom購読を追加（管理権限） |
| `/rss-list`                      | 購読中フィード一覧             |
| `/rss-remove id:<ID>`            | 購読を停止（管理権限）         |

RSSは60秒ごとに新着を確認し、記事IDで重複排除して指定チャンネルへ通知します。購読と記事履歴はDBへ保存されます。

| コマンド                   | 内容                     |
| -------------------------- | ------------------------ |
| `/remind`                  | 指定分後に一度だけ通知   |
| `/reminders`               | 自分のリマインダー一覧   |
| `/remind-cancel id:<ID>`   | リマインダーを取消       |
| `/notify`                  | 繰り返し可能な通知を設定 |
| `/notify-cancel id:<ID>`   | カスタム通知を取消       |
| `/schedule`                | DB保存付き予約通知       |
| `/announce-schedule`       | 管理権限付き予約告知     |
| `/schedule-list`           | 自分の予約通知一覧       |
| `/schedule-cancel id:<ID>` | 予約通知を取消           |
| `/birthday set`            | 誕生日を登録・更新       |
| `/birthday list`           | サーバーの誕生日一覧     |
| `/birthday remove`         | 自分の誕生日を削除       |

## コミュニティ・管理

| コマンド                              | 内容                     |
| ------------------------------------- | ------------------------ |
| `/announce message:<本文>`            | 管理者告知               |
| `/poll`                               | ボタン式アンケート       |
| `/suggest text:<本文>`                | 提案と賛否投票           |
| `/ticket topic:<種類>`                | 問い合わせチャンネル作成 |
| `/warn user:<ユーザー> reason:<理由>` | 警告を記録               |
| `/modlog`                             | モデレーション履歴       |
| `/audit-search`                       | 監査ログ検索             |
| `/slowmode seconds:<秒数>`            | 低速モード設定           |
| `/lock` / `/unlock`                   | チャンネルロック管理     |
| `/purge count:<件数>`                 | メッセージ一括削除       |

## ロール・VC・監視

| コマンド                            | 内容                   |
| ----------------------------------- | ---------------------- |
| `/role`                             | ロール付与・削除       |
| `/autorole`                         | 参加時の自動ロール設定 |
| `/role-menu`                        | ロール付与ボタンの投稿 |
| `/role-temp`                        | 期限付きロール付与     |
| `/nickname`                         | ニックネーム設定・解除 |
| `/verify`                           | 認証ボタン投稿         |
| `/timezone zone:<IANAタイムゾーン>` | タイムゾーン設定       |
| `/vc-recruit`                       | VC参加者募集           |
| `/health-alert-test`                | 死活監視通知テスト     |
| `/health-history`                   | 障害・復旧履歴         |

管理権限が必要なコマンドでは、Discordの権限チェックとBotの対象チャンネル権限が必要です。

参加時の自動ロールは、環境変数`COMMUNITY_AUTO_ROLE_BLACKLIST_USER_IDS`にDiscordユーザーIDをカンマ区切りで指定すると、そのユーザーには付与されません。例: `123456789012345678,987654321098765432`。ブラックリスト判定は参加イベントのユーザーIDと完全一致で行い、設定変更後はCommunity Botの再起動が必要です。
